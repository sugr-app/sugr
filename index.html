sugrDesktop apps with Java and web tech

Java backend + React (or any web) frontend, rendered in the OS-native webview, shipped as a single ~20-30MB binary via GraalVM native-image.

Quickstart
How it works

No embedded browser

Uses the OS's built-in webview (WebView2 on Windows, WKWebView on macOS, WebKitGTK on Linux) - no bundled Chromium.

Typed bridge, no reflection

Annotate a method with @Bind, get a generated dispatcher and a typed TS stub - no hand-written JSON, no runtime reflection (native-image friendly by construction).

Small, real binaries

GraalVM native-image compiles the whole app to a single native executable - no JVM required at runtime.
